# MIZAN AI (ميزان)

Intelligence with Integration.

AI Investment Intelligence · Financial Governance · Sustainability

A hackathon demonstration platform for public-sector decision-makers. It is **not** an official UAE government system. All records, amounts, energy figures and outcomes are **synthetic demonstration data**.

This project was bootstrapped with [Lovable](https://lovable.dev).

## Development

You need Node.js and npm.

```sh
npm i
npm run dev
```

```sh
npm test
```
